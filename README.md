# tapehive

Tape filesystem hive paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/tapehive/

## Install / run

```bash
git clone https://github.com/theworker02/tapehive.git
cd tapehive
node src/cli.js
node --test
```
